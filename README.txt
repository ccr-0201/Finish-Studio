5cmArchi - trinh dien vat lieu hoan thien tren trinh duyet
===========================================================
Noi dung: index.html (trang chinh) + thu muc libs/ (thu vien 3D, IFC). Khong can may chu, khong can cai dat.

CHAY THU TREN MAY
  Mo file index.html bang Chrome / Edge / Firefox.

DUA LEN MANG (mien phi, chon mot cach)
  1. Netlify: vao app.netlify.com/drop, keo tha CA THU MUC site (hoac file zip da giai nen).
  2. Cloudflare Pages: Create project > Direct Upload > tai thu muc len.
  3. GitHub Pages: tao repo, upload toan bo file, Settings > Pages > chon nhanh main.

GAN TEN MIEN 5cmarchi
  - Ten mien khong phan biet hoa thuong: 5cmArchi = 5cmarchi. Can mua phan duoi, vi du 5cmarchi.com hoac 5cmarchi.vn
    tai nha dang ky (Namecheap, GoDaddy, Mat Bao, PA Viet Nam...).
  - Trong Netlify/Cloudflare/GitHub: Domain settings > Add custom domain > nhap 5cmarchi.com,
    roi tro DNS theo huong dan hien ra (CNAME hoac A record). HTTPS duoc cap tu dong sau vai phut.
  - Luu y: kiem tra ten mien con trong tai nha dang ky truoc khi mua.

LUU Y
  - Font chu (Google Fonts) tai tu mang; mat mang trang van chay voi font he thong.
  - Lan dau mo file IFC se nap bo doc IFC (~5 MB) tu thu muc libs.
